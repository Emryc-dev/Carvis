# Learning path

1. **Python:** types, functions, classes, exceptions, modules, async context managers and tests. Move on when you can write and test a small package.
2. **HTTP:** methods, URLs, headers, status codes, JSON, multipart, authentication and idempotency. Move on when you can diagnose a request with curl.
3. **FastAPI:** routes, dependencies, schemas, middleware and OpenAPI. Build a CRUD API with consistent errors.
4. **PostgreSQL:** tables, constraints, joins, indexes, transactions and query plans. Be able to explain durability and a transaction boundary.
5. **SQLAlchemy/Alembic:** mappings, sessions, eager loading, async queries and reviewed migrations. Create/upgrade/rollback a disposable schema.
6. **Redis:** cache-aside, TTL, namespaced keys, invalidation and atomic rate limits. Know which data must remain in PostgreSQL.
7. **Image processing:** pixels, channels, formats, dimensions, EXIF, resize quality and decompression risk. Validate and normalize safely.
8. **AI APIs:** timeouts, retries, structured outputs, cost, evaluation, provider abstraction and hallucination. Build a schema-validated call.
9. **Machine learning:** arrays, loss, gradient descent, splits, metrics, leakage, bias and inference.
10. **Deep learning/computer vision:** tensors, backpropagation, CNNs, augmentation, transfer learning, detection and segmentation.
11. **Transformers/LLMs:** tokenization, embeddings, attention, pretraining, fine-tuning, retrieval and evaluation.
12. **Multimodal AI:** vision encoders, fusion, grounding, calibration, safety and production monitoring. Finish by evaluating CarVision on a held-out dataset instead of judging a few demos.
